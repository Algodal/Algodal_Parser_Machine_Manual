# Algodal Parser Machine

APM is a commercial parser generator that produces LR parsers. A shared Virtual Machine runs a compact Parser Program, so one codebase can run many different parsers with minimal dependencies.

This is the official manual of the Algodal Parser Machine (APM) and its language, the Algodal Parser Machine Language (APML).

Here, you can:
* reference the language syntax and features
* reference implementation in your own project
* reference parsing samples
* reference latest benchmark tests
